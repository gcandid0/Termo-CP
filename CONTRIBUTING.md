# Contribuindo com o TERMO-CP

Obrigado pelo interesse em contribuir com o TERMO-CP! 🎉

⚠️ **Atenção:** o TERMO-CP está em processo de **registro junto ao INPI** e seus direitos
autorais são reservados aos autores e à Universidade Federal de Rondonópolis (UFR).
Consulte o arquivo [LICENSE](LICENSE) antes de propor qualquer contribuição — em
particular, contribuições que resultem em código incorporado ao projeto podem exigir
que o(a) colaborador(a) ceda os direitos correspondentes aos autores originais.

## Tipos de contribuição bem-vindos

- Relato de bugs e inconsistências nos cálculos termodinâmicos
- Sugestões de melhorias de interface, usabilidade ou desempenho
- Sugestões de novas substâncias, processos ou funcionalidades educacionais
- Correções de documentação (README, comentários, etc.)

## Como relatar um problema

Abra uma [issue](https://github.com/gcandid0/Termo-CP/issues) descrevendo:

- O comportamento esperado e o comportamento observado
- Passos para reproduzir o problema
- Propriedades/valores de entrada utilizados na simulação (quando aplicável)
- Prints da interface, se ajudarem a ilustrar o problema

## Propondo alterações de código

1. Entre em contato previamente com os autores (veja e-mails no [README](README.md#-autores))
   para alinhar o escopo da contribuição, dada a natureza do software em processo de registro.
2. Faça um fork do repositório e crie uma branch descritiva:
   ```bash
   git checkout -b feature/nome-da-feature
   ```
3. Implemente e teste suas alterações localmente.
4. Envie um Pull Request explicando a motivação e o funcionamento da mudança.

## Código de conduta

Seja respeitoso(a). Críticas construtivas são bem-vindas; ataques pessoais não.
