Memorial de Cálculo Passo-a-Passo

1
Levantamento de Propriedades
No processo isocórico (volume constante), a primeira etapa foca na definição do estado inicial e final, garantindo que o volume específico permaneça inalterado.
ESTADO 1 v1 = {{ volume_especifico|floatformat:6 }} m³/kg
u1 = {{ energia_interna }} kJ/kg
s1 = {{ entropia_especifica }} kJ/kg.K
ESTADO 2 v2 = {{ volume_especifico2|floatformat:6 }} m³/kg
u2 = {{ energia_interna2 }} kJ/kg
s2 = {{ entropia_especifica2 }} kJ/kg.K
2
Trabalho de Fronteira (W)
Como os limites do sistema não se movem (pistão travado) e a massa é constante, o volume total do sistema não sofre alteração. Logo, o trabalho de fronteira realizado é nulo.
Dedução Teórica (Volume Constante):
1. Definição de Trabalho Total: W = ∫ P dV
2. Sendo V = m · v, e ambos constantes, V1 = V2
3. Como não há variação (dV = 0): W = ∫ P · 0
∴ W = 0 (Processo Isocórico)
W = 0 kJ
3
Primeira Lei e Calor Trocado (Q)
Pela 1ª Lei da Termodinâmica para um sistema fechado rígido, todo o calor transferido para o sistema resulta diretamente na variação da energia interna total (considerando a massa do sistema).
Dedução Teórica (Primeira Lei):
1. 1ª Lei Sist. Fechado: Q - W = ΔU
2. Como W = 0: Q = (U2 - U1)
3. Introduzindo a massa (U = m · u): Q = m · (u2 - u1)
∴ Q = m · (u2 - u1)
Q = m × (u2 - u1)
Q = 1 × ( {{ energia_interna2 }} - {{ energia_interna }} )
Q = {{ Calor }} kJ
4
Segunda Lei e Entropia Gerada (Sger)
O balanço de entropia determina se o processo é fisicamente possível. Calculamos a variação de entropia do sistema (levando a massa em consideração) menos a entropia transferida com o calor para a vizinhança.
Dedução Teórica (Balanço de Entropia):
1. Balanço geral (Sist. Fechado): Sin - Sout + Sger = ΔSsist
2. Transf. de entropia por calor e Entropia total (S = m · s):
    (Q / Tviz) + Sger = m · (s2 - s1)
3. Isolando a entropia gerada:
∴ Sger = m · (s2 - s1) - (Q / Tviz_K)
Sger = m × (s2 - s1) - [ Q / (Tviz + 273.15) ]
Sger = 1 × ({{ entropia_especifica2 }} - {{ entropia_especifica }}) - [ {{ Calor }} / ({{ TempViz }} + 273.15) ]
Sger = {{ Sger }} kJ/K
