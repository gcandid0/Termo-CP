Cálculo do Trabalho Isotérmico (w)
Para um processo isotérmico de um gás ideal (T = cte), a pressão P varia inversamente com o volume, P = RT/v. O trabalho é obtido integrando essa relação.
Dedução Teórica (Trabalho de Fronteira):
1. Definição de Trabalho: w = ∫ P dv
2. Substituindo P = RT/v: w = ∫ (R·T / v) dv
3. Como R e T são constantes: w = R·T ∫ (1/v) dv
∴ w = R · TK · ln(v2 / v1)
w = R × T × ln(v2 / v1)
w = {{ R }} × ( {{ T }} + 273.15 ) × ln( {{ v2|floatformat:6 }} / {{ v1|floatformat:6 }} )
w = {{ W12 }} kJ/kg
3
Primeira Lei e Calor Específico (q)
Para um gás ideal, a energia interna (u) depende apenas da temperatura. Como a temperatura é constante (Isotérmico), a variação de energia interna é nula (Δu = 0).
Dedução Teórica (Calor Isotérmico):
1. Balanço de energia: q - w = Δu
2. Como T = cte, Δu = 0: q - w = 0
∴ q = w
q = w
q = {{ W12 }}
q = {{ Q12 }} kJ/kg
4
Segunda Lei e Entropia Gerada (sger)
Como a temperatura é constante, a variação de entropia específica do Gás Ideal (Δs) depende apenas da variação de pressão (ou volume). Ao subtrair a entropia transferida por calor, obtemos a entropia gerada.
Dedução Teórica (Entropia - Gás Ideal):
1. Variação de Entropia (Geral): Δs = Cp0 · ln(T2 / T1) - R · ln(P2 / P1)
2. Como T1 = T2, ln(1) = 0: Δs = - R · ln(P2 / P1)
3. Balanço de Entropia: sger = Δs - (q / Tviz)
∴ sger = [ - R · ln(P2 / P1) ] - [ q / Tviz ]
sger = [ -R × ln(P2 / P1) ] - [ q / (Tviz + 273.15) ]
sger = [ -{{ R }} × ln( {{ p2 }} / {{ p1 }} ) ] - [ {{ Q12 }} / ( {{ Tviz }} + 273.15 ) ]
sger = {{ Sger }} kJ/kg·K
