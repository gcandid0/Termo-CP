Condição de Processo Adiabático e Reversível
Por ser Adiabático (isolado termicamente), a troca de calor é nula. Por ser Reversível, não há geração de entropia.
Dedução Teórica (Isentrópica):
1. Balanço de Entropia Total: ΔS = (Q / Tviz) + Sger
2. Se Adiabático (Q = 0) e Reversível (Sger = 0): ΔS = 0 + 0 = 0
3. Como ΔS = m · (s2 - s1): m · (s2 - s1) = 0
∴ s2 = s1 (Processo Isentrópico)
s2 = s1 = {{ entropia_especifica }} kJ/kg.K
Q = 0 kJ | Sger = 0 kJ/K
3
Cálculo do Trabalho via Primeira Lei (W)
Em um sistema fechado (cilindro-pistão) sem troca de calor, todo o trabalho realizado equivale à variação negativa da energia interna do sistema, considerando a massa total.
Dedução Teórica (Trabalho Total):
1. 1ª Lei Sist. Fechado: Q - W = ΔU
2. Sendo Adiabático (Q = 0): -W = (U2 - U1)
3. Invertendo o sinal: W = (U1 - U2)
4. Introduzindo a massa (U = m · u): W = m · (u1 - u2)
∴ W = m · (u1 - u2)
W = m × (u1 - u2)
W = 1 × ( {{ energia_interna }} - {{ energia_interna2 }} )
W = {{ Trabalho }} kJ
